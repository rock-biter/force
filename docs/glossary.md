# Glossary

Technical terms in plain words. The number is the logbook chapter where each one first appears.

| Term | What it means | Ch. |
| --- | --- | --- |
| **Broad phase** | A rough check that discards pairs of objects too far apart to touch | [001](./logbook/001-the-flip-book.md) |
| **Constraint** | A rule objects must obey, such as "do not pass through each other" | [001](./logbook/001-the-flip-book.md) |
| **Contact** | The result of a collision: where two objects touch, in which direction, and how far they overlap | [001](./logbook/001-the-flip-book.md) |
| **Integration** | The calculation that updates position from velocity | [001](./logbook/001-the-flip-book.md) |
| **Narrow phase** | A precise check, on the real shapes, of the pairs that survived the broad phase | [001](./logbook/001-the-flip-book.md) |
| **Physics engine** | A program that works out how objects move, one small step at a time | [001](./logbook/001-the-flip-book.md) |
| **Solver** | The part of the engine that corrects velocities so constraints are obeyed | [001](./logbook/001-the-flip-book.md) |
| **Timestep** | The jump in time of each step, often 1/60 of a second | [001](./logbook/001-the-flip-book.md) |
